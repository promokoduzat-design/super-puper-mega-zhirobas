## 1.3

Опция `-u` понадобилась, потому что `students.py` был новым неотслеживаемым файлом. Обычный `git stash` сохраняет изменения отслеживаемых файлов, а `-u` включает также неотслеживаемые файлы. После `git stash pop` изменения восстановлены.

## 2.6

После `git reset --soft HEAD~1` ветка указывает на первый коммит, а изменения второй версии остаются подготовленными к коммиту: режим `--soft` сохраняет индекс и рабочие файлы.

После `git reset --mixed HEAD~1` ветка также указывает на первый коммит, но индекс возвращается к первой версии. Изменения второй версии остаются только в рабочем файле и не подготовлены к коммиту.

## 2.7

Старый коммит остался в истории, потому что `git revert` не удаляет его, а создаёт новый коммит с обратными изменениями. После отмены третьего коммита в истории четыре коммита, а `app.py` содержит первую и вторую версии.
